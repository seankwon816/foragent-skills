Security Policy

Scope
This policy covers the executable scripts, hooks, and configuration templates under `templates/` and `skills/` in the `seankwon816/foragent-skills` repository.

Reporting a Vulnerability
If you find a security bug in any script or configuration template in this repository, such as command injection, unsafe file permissions, or credential exposure, please report it privately by email to `sean@sjksystems.com`.

Do not report security vulnerabilities through public GitHub issues or pull requests. Include the file path, reproduction steps, and the affected operating system or shell version in your email.

Response Timeline
We acknowledge vulnerability reports within 3 business days and will follow up with a fix timeline once the issue is reproduced.
